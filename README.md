# Sessio

Scheduling + discovery platform for independent sports coaches. React + TypeScript + Supabase, hosted on Vercel.

## Stack

- React + TypeScript + Vite
- Supabase (Postgres, Auth, Storage, Edge Functions)
- Tailwind CSS + shadcn/ui
- Vercel (hosting)

## Setup

```sh
bun install
bun run dev
```

## Environments

- **Production:** sessio-topaz.vercel.app (main branch)
- **Preview:** auto-deployed from dev branch
