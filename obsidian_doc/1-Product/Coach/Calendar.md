# Coach — Calendar

Full schedule across all lessons (group + individual). The "where do I need to be and is everyone showing up" view.

## Sections

- **Weekly view** — all lessons across all lessons. Each shows: lesson name, type badge (group/individual), time, venue, fill status.
- **Lesson detail** (tap into a lesson):
  - Athlete list: confirmed / pending / declined (group) or single athlete status (individual)
  - Open spots + waitlist status (group only)
  - Backfill activity (group only)
  - Location with map link
  - Manual override: add/remove athlete
  - Quick action: "Message" — opens lesson chat without leaving Calendar

## Interactions

- Swipe between weeks
- Color coding by status: confirmed (green), has open spots (yellow), at risk (red)
- Quick action: send reminder to pending athletes

## How it differs from Athlete calendar

Coach sees all lessons, all athletes' statuses, and can take actions. Athlete only sees their own confirmed lessons.
