# Coach — Profile

The coach's public face on the platform + account management.

## Public profile (what athletes see in Search)

- Photo, name, sport(s), location
- Bio / description
- Intro video (optional, short)
- Star rating (out of 5) + review count
- Available groups with open spots

## Profile editor

- Edit all public fields
- Preview mode: see exactly what athletes see
- Upload/replace video

## Reviews

- Read all reviews from athletes
- Respond to reviews (public reply)
- Cannot edit or delete athlete reviews
- Rating shown publicly only after minimum 3 reviews

## Account settings

- Notification preferences (email for now)
- Invite link management
- Account info (email, password)
