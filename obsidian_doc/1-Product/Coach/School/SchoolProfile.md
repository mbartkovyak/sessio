# School — School Profile

The school's public page. Discoverable in Search alongside individual coach profiles.

## What athletes see

- School name, sport(s), location
- Short description (written by owner)
- List of coaches: photo, name, star rating, bio snippet
- Tap a coach → goes to that coach's full individual profile

## What the owner edits

- School name, sport(s), location
- Description
- Profile photo / logo
- Which coaches are shown (all members shown by default)
- Preview mode: see exactly what athletes see

## Discovery in Search

- Athletes can filter Search by: individual coaches, schools, or both
- School card in results: name, sport, location, number of coaches, coach rating range (e.g. "3 coaches · 4.2–4.8★")
- No aggregate school rating in MVP — too easy to game with a new school
