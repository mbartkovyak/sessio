# Discovery Calls

## Decision tree

```
Is the coach independent (no facility/front desk)?
├── YES → Does he run groups at scale (50+ clients)?
│   ├── YES → 🔥 Strong fit (Kajtek Kossakowski, Witek Sadaj)
│   │         Pain: manual coordination breaks at scale
│   │         Buyer: the coach/owner directly
│   └── NO → Weak fit (Grzegorz Żmuda, Czarek/Marta)
│            Low volume or part-time → no urgent pain
└── NO → Works at a facility with admin support
    └── ❌ Not a fit (Doug Stutsman, Caswell Tennis)
          Pain absorbed by front desk/website
          Buyer would be the facility (B2B) — different GTM
```

## Key patterns so far

1. **Independent coach/school owners scaling beyond ~50 clients** = where the pain lives
2. **Facility-employed coaches** = no pain, not the buyer
3. **Part-timers with <30 clients** = manageable manually, no urgency
4. **Office workers / admin staff** = the actual day-to-day user at school scale
5. **Excel + WhatsApp** = universal default in Poland. Breaks at ~100+ clients
6. **Twój Tenis / ActiveNow** = existing tools, but neither solves scheduling + confirmation well
