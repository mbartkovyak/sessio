# Landing page demo videos

Drop final demo videos here. The Landing page's `DemoPlayer` auto-detects these files; if they're missing, a "Demo coming soon" overlay renders in their place.

Expected files:

- `demo-coach.mp4` + `demo-coach.webm` — short autoplay loop (10–15s, muted, ~1080p, target <3MB)
- `demo-coach-full.mp4` — full 90-sec demo (plays in modal on "Watch demo" click)
- `demo-coach-poster.jpg` — first-frame poster shown before video loads

- `demo-athlete.mp4` + `demo-athlete.webm` — athlete-side short loop
- `demo-athlete-full.mp4` — athlete-side full demo
- `demo-athlete-poster.jpg` — athlete-side poster

Videos reach users via Capgo OTA — no store release needed when swapping in new recordings.
